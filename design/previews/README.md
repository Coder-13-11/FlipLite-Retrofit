# Design views

These are renders of the project's geometry and named component data, not photographs or native CAD editor screenshots. No image-generation model is used for these views. AI assisted in writing the underlying design and rendering code.

- wall-preview.png: mechanical arrangement from exported STL parts, with reference envelopes.
- fan-parts.png: separate fan parts and a fit coupon.
- pcb-preview.png: component placement from netlist.json, not a routed board.
- pcb-3d-preview.png: simplified component/body envelopes, not vendor 3D models.
- schematic-power.png and schematic-control.png: pin-to-net tables, not native EDA schematic captures. Open node.sch for the editable schematic.

No whole-system image is provided because a complete assembly including battery, sensors and wiring has not been finished. Captions retain those limitations.
